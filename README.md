# EventSphere

**Discover. Explore. Participate.**

EventSphere is a web platform for **UET Taxila** students to discover departmental societies, browse upcoming events and register in about a minute.

## The Problem

After a long lecture, society members often start introducing themselves while students are already tired and just want to leave. Announcements get lost in class or buried in WhatsApp groups, and there is no single place to see what each society does or how to join.

## The Solution

EventSphere puts societies, events and registration on one simple page. Students can browse at their own time instead of sitting through speeches after class.

## Features

- **Society cards:** name, short intro and contact details, with a "Read More" option for the full story
- **Category filter:** show only Tech, Sports or Cultural societies
- **Search:** find societies and events by keyword
- **Upcoming events:** event name, date, venue and the society hosting it
- **Registration form:** name, roll number and society, with input validation and an instant confirmation

## Scope

EventSphere currently focuses on **departmental societies** at UET Taxila. Keeping the scope small makes the project easier to build, test and keep up to date. More societies and features can be added later.

2. Open the `EventSphere` folder
3. Open `index.html` in your browser (or use the VS Code Live Server extension)
